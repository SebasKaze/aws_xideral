# Tarea 1. Instalación de Ubuntu, Docker, Python y Notebook
## Ubuntu WSL
Para la instalacion de Ubuntu en Windows es necesario instalar una virtualizacion de linux.
Para ello hay que utilizar **Power Shell** de Windows y escribir el siguiente comando.
```bash
wsl --install
```
En caso de querer cambiar la distribución utilizar el siguiente comando. Aquí se puede cambiar la distribución distinta a Ubuntu
```bash
wsl.exe --install -d [Distro]
```
Con esto estamos listos para empezar.

## Docker
Para la instalación de Docker hay que seguir los siguientes pasos en orden. 
En la consola de WSL colocar:
```bash
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc docker-buildx podman-docker containerd runc | cut -f1)
```
Esto elimina versiones anteriores de paquetes que puedan generar algún conflicto.

Lo siguiente es instalar las claves GPG:

```bash
sudo apt update
sudo apt install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```
Y añadir el repositorio a Apt

```bash
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF
```
```bash
sudo apt update
```
Con esto listo podemos pasar a la instalación de Docker:

```bash
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```
Si todo salio bien, podemos probar el siguiente comando para correr la imagen **hello-world**:

```bash
sudo docker run hello-world
```
Esto nos indicara que Docker esta corriendo de manera correcta.
## Post instalación de Docker
Hay algunas consideraciones extras despues de la instalacion de Docker

```bash
sudo groupadd docker
sudo usermod -aG docker $USER
newgrp docker
```
Esta serie de comandos permiten correr Docker sin necesidad de sudo, pero hay que tener cuidado en que contexto se usa.

Para corroborar que todo funciono puedes utilizar el siguiente comando: 
```bash
docker run hello-world
```

## Instalacion de pyenv
Pyenv es una herramienta que permite gestionar multiples versiones de Python en un mismo sistema.

Para su instalación debemos seguir los siguientes comandos: 
```bash
sudo apt install -y \
  make \
  build-essential \
  libssl-dev \
  zlib1g-dev \
  libbz2-dev \
  libreadline-dev \
  libsqlite3-dev \
  curl \
  llvm \
  libncursesw5-dev \
  xz-utils \
  tk-dev \
  libxml2-dev \
  libxmlsec1-dev \
  libffi-dev \
  liblzma-dev
```
Clonamos el repositorio:
```bash
git clone https://github.com/pyenv/pyenv.git ~/.pyenv
```
Comprobamos si todo está en orden:
```bash
ls ~/.pyenv
```
```bash
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo 'export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init - zsh)"' >> ~/.zshrc
source ~/.zshrc
pyenv --version
```
Con el listado de versiones instalamos la 3.14 para este ejercicio:
```bash
pyenv install --list | grep " 3.14"

pyenv install 3.14.7

pyenv versions
```
Y volvemos global la version necesaria
```bash
pyenv global 3.14.7

pyenv rehash

python --version
```
## Jupyter
Para crear un workspace de Jupyter vamos a utilizar los siguiente comandos:
```bash
mkdir -p ~/jupyter
cd ~/jupyter
python --version
```
Con el comando deberiamos de ver "Python 3.14.7"

Ya una vez verificando que todo funciono colocar el siguiente comando que nos dara un link para acceder a Jupyter Notebook.
```bash
python -m venv .venv

source .venv/bin/activate

python -m pip install --upgrade pip


pip install notebook

pip install ipykernel

jupyter notebook
```
